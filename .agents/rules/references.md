# References — study before designing
## Indie agent skills (vendored in indie-skills/)
- pbakaus/impeccable (~90k★) https://github.com/pbakaus/impeccable — design-critique skill with commands, anti-slop vocabulary
- Leonxlnx/taste-skill (~103k★) https://github.com/Leonxlnx/taste-skill — "taste" rules against generic AI layouts
- emilkowalski/skills (~50k★) https://github.com/emilkowalski/skills — animation craft from Sonner/Vaul author
- ibelick/ui-skills (~10k★) https://github.com/ibelick/ui-skills — baseline UI + motion-performance fixes
- vercel-labs/web-interface-guidelines https://github.com/vercel-labs/web-interface-guidelines — interface detail checklist
- raunofreiberg/interfaces https://github.com/raunofreiberg/interfaces — Rauno's original interface guidelines (older, still gold)
## Award-level source code
- lusionltd/WebGL-Scroll-Sync https://github.com/lusionltd/WebGL-Scroll-Sync — Lusion's DOM↔WebGL scroll sync
- lusion.co https://lusion.co — benchmark: concept-driven WebGL, transitions
- brunosimon/folio-2019 https://github.com/brunosimon/folio-2019 and folio-2025 https://github.com/brunosimon/folio-2025 — playable 3D portfolio, physics, baked lighting
- akella (Yuri Artiukh) https://github.com/akella — fake3d (depth parallax), DistortedPixels (hover grid distortion), ExplodingObjects
- edankwan https://github.com/edankwan — The-Spirit (GPGPU particles), PerspectiveTransform
- codrops https://github.com/codrops — ScrollBlurTypography, Scroll3DGrid, GridZoom, ColumnScroll, LineTextHoverAnimations, FullscreenScroll, SlideshowAnimations
- darkroomengineering/satus https://github.com/darkroomengineering/satus — Next.js starter from Lenis authors
- darkroomengineering/lenis https://github.com/darkroomengineering/lenis — smooth scroll
- 14islands/r3f-scroll-rig https://github.com/14islands/r3f-scroll-rig — R3F meshes tracking DOM
## Learning / inspiration
- https://threejs-journey.com — Bruno Simon's course (shaders, physics, perf)
